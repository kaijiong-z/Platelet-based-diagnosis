# Platelet-based diagnosis

R code accompanying the manuscript (platelet-based diagnostic model).

## Contents

- `fig2.R` – `fig7.R`: code for generating Figures 2–7
- `plot_evaluate_functions.R`: shared plotting and model-evaluation functions
- `boot_ci_and_compare.R`: bootstrap confidence intervals and model comparison

## Notes

Scripts load `.rdata` data files from the same directory; data files are not included in this repository.
